# 0.46 Relic Chamber & Reliquary — Behavioral Bug-Bash

This checklist replaces feature expansion until 0.46 is frozen.

## Fold 6 — Oracle → Relic Chamber

1. Restore or draw a provider-free canonical TRIAD.
2. Tap Thesis card body, not only the OPEN RELIC label.
3. Chamber must visibly replace the Oracle surface.
4. Close and reopen the same card.
5. RELIC HISTORY must increase monotonically.
6. Repeat for Antithesis and Synthesis.
7. Repeat after hard refresh/continuity restore.
8. Repeat after OPEN MEMORY from Reliquary.

Failure criterion: a card only lifts/animates without mounting the Chamber.

## Fold 6 — Reliquary

1. KEEP THIS READING seals the current reading and opens THE RELIQUARY.
2. Save the same reading twice: entry count must not increase on the second save.
3. Hard refresh: memory remains.
4. OPEN MEMORY restores exact question, card IDs, ReadingRecord relations/patterns, and available artwork.
5. Missing-artwork condition may lose only artwork, never ReadingRecord/card identity.
6. FORGET requires RELEASE confirmation.
7. Forgetting one memory leaves other memories intact.
8. SCRIBE & EXPORT still exposes HTML, JSON restore/export, and Grand Forge.
