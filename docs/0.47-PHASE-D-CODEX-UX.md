# 0.47 Phase D — Codex Fold UX Stabilization

Issue: #55

This is the final UX-only slice before the 0.47 runtime candidate is frozen. The semantic behavior from Phases A–C is already accepted on the Samsung Galaxy Z Fold 6.

## Accepted semantic behavior entering Phase D

- interpretive-lens changes keep the current ReadingRecord open;
- relation-method changes invalidate the current ReadingRecord and return to Threshold with the question preserved;
- Tarot-system changes invalidate/rebind active authority and return to Threshold with the question preserved;
- automated candidate gate passed 53 test files / 253 tests plus production build and `git diff --check`;
- the accepted runtime candidate is exactly six local modified files and remains uncommitted.

## Phase D goals

1. Make the Codex drawer wider and more legible on an unfolded Fold without consuming the entire screen.
2. Keep the Codex close affordance visible while scrolling.
3. Remove the floating audio-control collision without changing audio state: hide the floating control only while Codex is open.
4. Convert Reading Doctrine from one long wall into occult disclosure sections.
5. Keep Tarot System and Interpretive Lenses open by default; collapse secondary axes behind immediately readable summaries.
6. Replace faint change warnings with the explicit `RECASTS CURRENT READING` warning for fact-affecting axes.
7. Preserve the visible epistemic firewall for interpretive lenses.
8. Replace the always-expanded 51-style list with a collapsible, searchable Style Library with bounded internal scrolling.
9. Keep Style authority explicitly presentation/image-direction only.

## Non-goals

Phase D must not change:

- semantic configuration vocabulary;
- Tarot source facts;
- relation calculations;
- ReadingRecord schema or provenance;
- persistence semantics;
- provider behavior;
- Eros behavior;
- visual-current/enchantment semantics;
- VR code;
- deployment or merge state.
