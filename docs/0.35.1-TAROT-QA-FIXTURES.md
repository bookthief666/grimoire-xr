# 0.35.1 — Deterministic Tarot Semantic QA

Status: IMPLEMENTED · EXACT-HEAD FOLD GATE PENDING

## Purpose

0.35 bound the Fold/2D Grimoire to the source-qualified Tarot semantic contract pinned from `bookthief666/tarot-archetype-vr`.

0.35.1 adds a provider-free regression surface so canonical Tarot semantics can be checked on the Fold without:

- Ollama;
- ComfyUI;
- Gemini;
- a Mac host;
- random card selection;
- ritual initialization;
- forging card images.

The harness must never become a second Tarot truth layer. It calls the same `canonicalTarotBridge.js` functions used by the application and self-grades the resulting ReadingRecord-shaped facts.

## CLI gate

Run:

```bash
npm run qa:tarot
```

Both fixtures must report PASS and emit deterministic semantic signatures.

## Browser gate

Run the normal Vite server on the test device, then open both QA routes. The top-level status and every self-grading row must read PASS.

This is a semantic QA surface, not a visual-design approval surface. It is intentionally sparse and diagnostic.

## Guardrails

- `/` remains the normal 2D application.
- `/vr` remains the existing VR application.
- `/qa/tarot` is provider-free and does not mutate user state.
- QA selection envelopes do not freeze reducer-owned card objects.
- the fixture definitions are assertions against the pinned upstream contract, not a replacement for it.
- no deploy or merge is authorized by this slice.
