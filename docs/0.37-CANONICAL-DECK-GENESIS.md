# 0.37 — Canonical Deck Genesis

Status: IMPLEMENTED · LOCAL ACTIVATION / FOLD GATE PENDING

Parent checkpoint: `0.36` accepted head `abba1a3fd08d87fa63951fd2802a3a7c16be1175`.

## Problem closed

Before 0.37, the ritual text model was required to emit 78 unique card-name strings. `RITUAL_SUCCESS` then attached canonical card IDs solely by array position. A model could therefore return 78 unique but renamed or reordered labels and silently bind the wrong visible relic to a canonical Tarot identity.

That violates the shared semantic architecture: model synthesis must never author identity truth.

## New invariant

`MODEL OUTPUT != TAROT IDENTITY`

Deck genesis is now deterministic:

1. The canonical 0..77 manifest supplies every stable card ID.
2. Book of Thoth uses reviewed, source-qualified Thoth display expressions.
3. Traditions whose expression packs are not yet source-qualified receive deterministic project compatibility labels, explicitly carrying no source IDs.
4. Ritual text output contains dossier + exactly three Oracle questions only.
5. Injected or legacy model card-name arrays are ignored by the activated reducer and rejected by the new structured ritual contract.

## Thoth examples

- `major.magician` -> `THE MAGUS`
- `major.priestess` -> `THE PRIESTESS`
- legacy index 8 / `major.fortitude` -> `LUST`
- legacy index 11 / `major.justice` -> `ADJUSTMENT`
- `major.temperance` -> `ART`
- `major.judgement` -> `THE AEON`
- `major.world` -> `THE UNIVERSE`
- Page compatibility rank -> `PRINCESS`
- Knight compatibility rank -> `PRINCE`
- King compatibility rank -> Thoth `KNIGHT`

The legacy numeric index remains only a compatibility coordinate; it does not define the visible expression.

## Provider-neutral structured tasks

The client now sends explicit structured task identity for:

- `ritual`
- `card`
- `oracle`

The server preserves the task through request normalization. Ollama continues schema grounding/repair, while Gemini receives the same post-generation semantic validation. Prompt inference remains only as backward compatibility for older clients.
