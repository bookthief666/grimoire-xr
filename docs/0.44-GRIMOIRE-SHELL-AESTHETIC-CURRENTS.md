# 0.44 — Grimoire Shell & Aesthetic Currents

Base: `f6d6c862724e65283fe3e8cac276df3ce599b990` (accepted 0.43 Threshold runtime)

## Product rule

**Simplify navigation, not imagination. Reduce confusion, not atmosphere.**

0.44 does not replace the accepted aesthetic with a minimalist redesign. It makes visual direction explicit and reversible so aggressive art-direction work cannot erase a liked prior state.

## Visual currents

### ARCANE OS

The accepted pre-0.44 scarlet / scanline / pixel-occult presentation. The new magical field is disabled in this profile and the existing animated canvas remains untinted.

This is the guaranteed return path if later visual experiments become too quiet, too manuscript-like, or too professional.

### RITUAL HYBRID — default

The intended everyday current: occult cyberpunk illuminated manuscript.

- accepted animated background preserved and lightly tinted;
- scarlet remains ritual current rather than disappearing;
- brass/gold carries canonical architectural emphasis;
- bone/ivory improves legibility;
- scanlines remain visible at reduced intensity;
- deterministic sigil halo, planetary glyphs, motes and marginalia add spatial depth;
- topbar and Codex drawer become layered ritual objects rather than generic red rectangles.

### LIVING BOOK

A Codex-forward alternative:

- warmer brass / ivory register;
- much quieter scanlines;
- manuscript-like drawer and shell depth;
- existing animated background remains underneath, sepia-tinted rather than deleted;
- the same magical field remains available at any Enchantment level.

## Enchantment intensity

Visual profile and visual density are orthogonal.

- `VEILED`
- `BALANCED`
- `VIVID`
- `EXALTED`

Changing motion/detail must never silently change the visual current.

This allows combinations such as:

- ARCANE OS + EXALTED
- RITUAL HYBRID + BALANCED
- LIVING BOOK + EXALTED

## Persistence and A/B access

Preferences are local presentation settings only.

Query overrides:

- `?look=arcane`
- `?look=ritual`
- `?look=book`
- `?fx=veiled|balanced|vivid|exalted`

The Codex drawer exposes the same controls without URL editing.

## Authority boundary

All profile definitions use:

`PROJECT_AUTHORED_PRESENTATION_PROFILE_NOT_SOURCE_FACT`

The new aesthetic layer cannot:

- call local or cloud providers;
- construct a Tarot deck;
- build or modify a ReadingRecord;
- compute relations;
- alter provenance;
- alter image-generation contracts.

The field is pointer-inert and `aria-hidden`.

## Reduced motion

Reduced motion freezes the new orbital/glyph/mote animation. It does not remove the selected visual current, canonical color hierarchy, typography or static ritual geometry.

## Acceptance

Automated:

```bash
npm run qa:aesthetic
node scripts/verify-0.44-aesthetic-currents.mjs
git diff --check
npm run check
```

Physical Fold acceptance:

1. ARCANE OS looks recognizably like the accepted 0.43 shell and retains the living red canvas/scanlines.
2. RITUAL HYBRID looks richer and more magical, not cleaner or emptier.
3. LIVING BOOK is warmer and more manuscript-like but not a plain professional UI.
4. Switching profiles is immediate and does not reset the reading/session.
5. Enchantment changes density independently of profile.
6. EXALTED remains usable on the Fold; no decorative layer intercepts touch.
7. Reduced-motion preference freezes new motion while retaining the visual design.
8. Reload restores the chosen current/intensity.
9. `?look=arcane&fx=exalted` provides a direct emergency return to the dense baseline.

## Non-goals

0.44 does not yet repaint every Threshold, Oracle, Relic, Spirit and Archive inner component. This slice establishes the reversible shell/current system first. Once accepted, subsequent art-direction slices can theme individual surfaces through the same data attributes instead of forking their logic.
