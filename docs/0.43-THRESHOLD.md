# 0.43 — The Threshold: Provider-Free First Reading

Base: accepted 0.42 Living Book Oracle at `bebb87cbf2d0fe50eb5bdfd0d9afb085baa9ebbb`.

## Product problem

The current first-run path asks for a subject and immediately invokes the text provider plus portrait generation before the user reaches the Tarot experience. A later Oracle consultation may then silently generate text and artwork for three cards before presenting a reading.

That makes the most important product loop dependent on the most expensive and fragile parts of the stack.

0.43 reverses that dependency.

## Product intent

The first meaningful loop becomes:

`ASK → DRAW THREE → WITNESS → READ → KEEP`

A first-time user can reach a canonical TRIAD reading while Ollama, ComfyUI, and the Grimoire API are all unavailable.

Provider-free does **not** mean source-free or simplified semantics. The Threshold uses the same canonical deck genesis, TRIAD binding, relation method, ReadingRecord, provenance, and Living Book surface as the advanced application.

## Default first contact

The landing surface becomes `THE THRESHOLD` and asks one primary question:

> What do you bring before the Grimoire?

`DRAW THREE`:

1. validates the question;
2. constructs the canonical 78-card deck locally if no deck is active;
3. selects three cards locally;
4. builds the canonical TRIAD ReadingRecord;
5. derives a deterministic reader-facing Witness from that record;
6. opens the existing Living Book.

It must not call:

- `/api/text`;
- `/api/image`;
- `fetchGemini`;
- `fetchImagen`;
- `fetchImageGeneration`;
- `generateCardData`.

## The Witness

The Witness is not model prose and not a historical quotation. It is a deterministic project-authored paraphrase of facts already attached to the ReadingRecord.

Examples:

- FRIENDLY → `Thesis and Antithesis strengthen one another.`
- INIMICAL outer pair → `Across the spread, Thesis and Synthesis stand contrary.`
- CENTER_BETWEEN_CONTRARIES → `Antithesis stands between those contraries and is treated as not much affected by either neighbor.`
- CARD_WITHOUT_SUIT_FAMILY → explicit statement that no elemental-dignity relation is asserted because a canonical suit family is absent.
- SOURCE_DOES_NOT_SPECIFY_PAIR → explicit statement that the reviewed source remains silent.

Witness authority:

`DETERMINISTIC_READING_RECORD_WITNESS`

The Witness must never mutate the ReadingRecord.

## Optional interpretation

A provider-free reading remains complete without generated prose.

The Living Book adds an explicit:

`REQUEST INTERPRETATION`

This action:

- receives the already-computed ReadingRecord;
- uses the existing canonical Oracle synthesis prompt;
- calls the text provider only;
- never calls card/image generation;
- preserves the Witness and exact ReadingRecord;
- marks returned prose `MODEL_GENERATED_INTERPRETATION`.

If the provider is unavailable, the canonical reading remains on screen and remains the last stable continuity checkpoint.

## Artwork

No artwork is generated during the Threshold or optional interpretation.

Unmanifested cards are valid relics. The Living Book renders them as deliberate unmanifested surfaces rather than failed loading states.

Future manifestation remains an explicit studio/relic action.

## Advanced workflow preservation

The existing full Ritual / Scriptorium / Forge workflow is not deleted in 0.43.

It moves under progressive disclosure:

`STUDIO & ARCHIVES`

That surface preserves:

- subject/name entry;
- existing dossier + portrait Ritual;
- selected legacy Tarot preset;
- art style;
- archive restore;
- VR prototype entry where supported.

This is a migration step, not removal of advanced capability.

`node scripts/apply-0.43-threshold.mjs`

- `src/App.jsx`

- Threshold imports;

- Threshold landing mount;

## Fold acceptance

With the API server intentionally OFF:

1. app opens to The Threshold;
2. user enters a question;
3. `DRAW THREE` opens a Living Book reading without network/provider error;
4. three canonical cards appear even without artwork;
5. Witness is visible;
6. relations and scholarly basis remain visible;
7. hard refresh restores the same provider-free reading through 0.40.1 continuity;
8. `NEW READING` returns to The Threshold;
9. `STUDIO & ARCHIVES` still exposes the full legacy studio route.

If the text API is later started:

10. `REQUEST INTERPRETATION` adds generated prose without changing card images;
11. no image job is submitted by that action.
