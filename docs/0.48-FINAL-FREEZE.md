## Why no shared package in 0.48

A shared package is not required to achieve authority de-duplication. The two clients still have different release histories and runtime concerns. Generated, contract-pinned artifacts give the Fold a reproducible authority boundary while preserving repository independence.

Shared-package extraction should be reconsidered only after:

- both clients consume the frozen contract for a full milestone without drift;
- repository/release governance is clarified;
- the package boundary can remain presentation-free and provider-free;
- extraction reduces maintenance burden rather than introducing synchronized-release coupling.
