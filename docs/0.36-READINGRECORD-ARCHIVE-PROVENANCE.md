# 0.36 — ReadingRecord archive + visible provenance

Status: IMPLEMENTED · APP ACTIVATION / FOLD GATE PENDING

Base: accepted `0.35.1` head `14d71b737063822f8828414922b5b35559e47637`.

## Objective

Make the canonical ReadingRecord survive the same lifecycle as the generated Grimoire:

`deterministic semantic facts -> model synthesis -> live Oracle -> archive -> restore`

Generated prose is never promoted to source truth during that lifecycle.

## Structured archive

`src/tarotBridge/archiveEnvelope.js`

Schema: `grimoire.xr.archive@2.0.0`.

The archive stores:

- exact semantic contract pin;
- author/configuration;
- deck/card data including canonical card IDs;
- current spread slots;
- current Oracle reading;
- generated answer with `MODEL_GENERATED_SYNTHESIS` authority;
- exact canonical ReadingRecord;
- selection continuity (`BOUND_TRIAD_CLOTH` / fallback);
- Spirit Box history and existing presentation data.

The parser also accepts older state/deck-shaped JSON and labels it `LEGACY_NO_CONTRACT_PIN` rather than inventing missing provenance.

A future/foreign contract is preserved but reported as `ARCHIVED_CONTRACT_MISMATCH`.

## Human-readable HTML

`src/tarotBridge/archiveHtml.js` replaces the old card-only HTML generator after App activation.

The archive includes:

- generated Oracle answer;
- explicit generated-prose authority;
- canonical position/card IDs;
- deterministic relation facts;
- relation-method authority;
- source IDs;
- unresolved source gaps;
- semantic contract pin;
- embedded structured archive JSON for forensic portability.

## Live Oracle provenance

`ReadingProvenancePanel.jsx` sits directly below generated Oracle prose and exposes the deterministic basis that existed before the LLM was called.

It does not ask the model to explain its own provenance.

## Restore behavior

The guarded App migration adds:

- `EXPORT RESTORABLE JSON`;
- `RESTORE JSON ARCHIVE`;
- reducer-level `RESTORE_ARCHIVE` rehydration;
- catalog-object re-resolution for style/tradition;
- warning when restoring a legacy or foreign semantic-contract archive.

Historical ReadingRecords are preserved rather than silently recomputed.
