# 0.39 — Relic Workspace

Status: IMPLEMENTED · LOCAL APP ACTIVATION / FOLD GATE PENDING

Parent checkpoint: accepted 0.38 head `75ab3c917965e1b723d40d8063689f384bd15e5e`.

## Product problem

0.38 made authority visible, but the focused-card modal still presented generation controls, canonical scholarship, generated exegesis, reflective metadata, prompt text, and render telemetry as one long vertical document. That was accurate but not a good instrument.

## 0.39 invariant

**THE CARD IS THE RELIC; EACH TASK GETS ITS OWN AUTHORITY LAYER.**

The focused-card right column becomes a four-mode workspace:

1. **RELIC** — immutable card identity, display-label authority, patina, manifestation state, compact source-qualified at-a-glance facts.
2. **CORRESPONDENCES** — reviewed canonical expression/correspondence fields, source IDs, semantic-contract pin; no model-generated reflection appears here.
3. **INTERPRETATION** — exegesis and reflective metadata, explicitly `NOT SOURCE FACT` and carrying their actual authority tag (`MODEL_GENERATED_*` or `LEGACY_UNCLASSIFIED_*`).
4. **GENERATION** — render provenance, seed/preset, preview/final/refine controls, generated visual direction, compiled image prompt.

The left-hand image remains the physical/visual relic. Card swipe navigation, modal framing, Forge handlers, and image-generation presets remain unchanged.

## Authority behavior

The workspace consumes `buildCardRelicAuthority` through a presentation model. It does not redefine Tarot facts.

For Book of Thoth, the deterministic Two of Wands QA fixture resolves:

- canonical ID `minor.staffs.two`
- display label `TWO OF WANDS`
- native title `DOMINION`
- element `FIRE`
- planet `MARS`
- zodiac sign `ARIES`
- reviewed source provenance from the canonical semantic contract

Generated exegesis, reflection metadata, and visual direction remain separate non-source layers.

For traditions without reviewed expression packs, the Correspondences mode states that the display is a project compatibility label and claims no historical-source authority.

## UX behavior

- workspace defaults to **RELIC** whenever a different card is opened;
- tabs are 2×2 on narrow Fold/mobile layouts and 4-across on wider screens;
- generation controls exist only under **GENERATION**;
- the previous `INSCRIBING TRUTH...` language is removed; generated prose is called interpretation;
- no provider is required to inspect the workspace QA surface.

## Guarded runtime activation

The committed branch does not remotely rewrite the large `src/App.jsx` surface. Run once on the exact branch checkout:

```bash
node scripts/apply-0.39-relic-workspace.mjs
```

The script performs only:

- `CardRelicAuthorityPanel` import -> `RelicWorkspace` import;
- focused-card right-column replacement with the workspace component;
- preservation of existing preview/final/refine/copy handlers through props.

It refuses activation if the accepted 0.38 modal parent shape has drifted.

Static gate:


Full gate:
