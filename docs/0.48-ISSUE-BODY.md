# 0.48 Cross-Client Conformance & Doctrine De-duplication

Planning-only until 0.47 freeze SHA is pushed.

## Preconditions

- 0.47 exact Fold-tested six-file runtime candidate is committed and pushed.
- 0.48 branch is cut from that exact SHA, never from an earlier support-only head.
- authoritative VR semantic contract remains pinned to `bookthief666/tarot-archetype-vr@f4534b4f92d88f3950ec0c9c211bfa4648cd08ea` (`grimoire.tarot.semantic.v1@1.0.0`).

## Goal

Prove executable semantic parity between the 2D/Fold Grimoire and the VR Tarot client before extracting any shared package. Remove duplicated doctrine only where parity evidence shows extraction is safer than continued mirroring.

## Phase A — client-neutral normalized snapshots

Both clients must emit the same presentation-free semantic snapshot covering:

- contract/component versions;
- 78-card canonical IDs in legacy 0..77 order;
- arcana/family/suit-family/rank identity;
- source-qualified Thoth expression and reviewed correspondence fields;
- source IDs and claim IDs;
- spread IDs and topology;
- supported relation methods;
- relation provenance vocabulary;
- deterministic fixture outputs.

UI state, VR geometry/input, Fold layout, generated prose/art, providers, visual current/enchantment and persistence implementation are excluded.

## Phase C — 0.47 semantic axes

Prove that orthogonal Fold configuration remains contract-safe:

- lens/theme/depth never alter card facts or deterministic relation truth;
- fresh RWS has no invented correspondence pack;
- explicit RWS + Crowley/LXXVIII may use direct relation-method provenance without RWS correspondence fiction;
- no `thoth_native` relation algorithm exists;
- `UNSPECIFIED` remains first-class;
- ReadingRecord semantic signature remains deterministic.

## Phase D — de-duplication inventory

After parity passes, classify duplicated responsibilities:

1. canonical identity/index map;
2. Thoth source-qualified data;
3. spread topology;
4. relation engine;
5. ReadingRecord normalization;
6. provenance normalization;
7. legacy migration tables.

For each choose one: upstream immutable artifact, shared pure module/package, or intentional client adapter.

No React/UI, provider, persistence, or VR presentation extraction.

## Acceptance before extraction

- exact 0.47 Fold freeze SHA recorded;
- exact VR contract SHA recorded;
- both normalized snapshots pass;
- all 78 identities and reviewed source claims match;
- Three-Aces and Major-gap outputs match exactly;
- contract pin drift fails loudly;
- both repositories pass existing full local checks;
- only then may shared-package extraction be proposed as a separate reversible slice.
