# 0.47 — Semantic & Ontology Integrity

Base: exact accepted 0.46 runtime `bc56a63773a4e41751f3fc1121fa6f07666e4bc1`.

Issue contract: #53.

## Why this milestone exists

The legacy `selectedTradition` control conflates independent concerns: Tarot system identity, correspondence source pack/profile, inter-card relation method, interpretive lens, ritual theme, and reading/explanation depth.

That coupling allows an interpretive choice such as Jungian Shadow, Bruno, Astarte, or another philosophical frame to silently change or disable Tarot-system authority. It also allows `SET_TRADITION` to change a label while leaving a live deck/reading bound to stale authority.

0.47 fixes that correctness defect before further product expansion.

## Semantic configuration

Schema: `grimoire.semantic.config@1`.

Orthogonal axes:

1. `tarotSystem`: `thoth`, `rws`, `marseille`
2. `correspondenceProfile`: `thoth_native`, `none`
3. `relationMethod`: `crowley_lxxviii_dignities`, `disabled`
4. `interpretiveLenses`: zero or more project-authored interpretive frames
5. `ritualTheme`: presentation/ritual framing; never a Tarot source fact
6. `readingDepth`: `neophyte`, `adept`, `magus`

Eros remains separate from semantic Tarot configuration.

## Interpretive lenses

Authority: `PROJECT_AUTHORED_INTERPRETIVE_LENS_NOT_TAROT_FACT`.

Current bounded catalog:

- Hermetic Qabalah
- Jungian Shadow & Individuation
- Enochian Visionary
- Chaos Magick
- Nightside / Bertiaux
- Alchemical Transformation
- Giordano Bruno — Mnemonic Eros
- Astarte / Venus Devotional
- Georges Bataille — Eroticism & Excess
- Nietzsche — Dionysian Becoming
- Neoplatonic Theurgy
- Thelemic Will & HGA

The lens catalog may shape philosophical emphasis, metaphor, reflection, generated prose, and imagery. It must never recalculate, replace, contradict, or invent canonical Tarot identity, correspondence, relation, provenance, or source claims.

Bataille is therefore allowed to frame a reading through excess, expenditure, taboo/transgression, continuity/discontinuity, sovereignty, sacrifice, and sacred/profane tension while leaving the Tarot engine untouched. The same firewall applies to every lens.

## Legacy compatibility and restore precedence

`TRADITIONS` remains only as migration/input-compatibility vocabulary during the transition.

Restore precedence is field-aware:

1. valid saved `semanticConfig` wins;
2. otherwise canonical Tarot axes recorded by an immutable ReadingRecord win;
3. interpretive lens/theme/depth use ReadingRecord fields only when that historical record actually contains them;
4. missing newer interpretive fields may fall back to legacy `selectedTradition` / `techLevel`;
5. if no ReadingRecord exists, deterministic legacy preset migration applies.

This prevents an old Jungian/Bruno session from losing its interpretive frame merely because its older ReadingRecord predates lens fields, while also preventing a legacy philosophy preset from overriding canonical Tarot system/relation truth already recorded in the reading.

Historical ReadingRecords are never rewritten by session migration. Unsupported historical vocabulary is projected conservatively for active prompt use rather than upgraded into a source claim.

## Transition rules

### Tarot-system change

- rebuild the canonical 78-card deck for the target system;
- preserve canonical card IDs;
- preserve creative/user-history layers such as artwork, exegesis, generation state, prompt state, and patina;
- rebuild display labels/authority from the target system;
- strip stale system-specific authority fields;
- clear focused card;
- invalidate the open reading;
- stop in-flight consultation state;
- if the Oracle is open, return to the Threshold while preserving the question.

### Correspondence-profile change

- do not rewrite card identity;
- clear focused card authority surface;
- invalidate the open reading;
- return an open Oracle to the Threshold with its question preserved.

### Relation-method change

- do not rebuild card identity;
- invalidate the open reading;
- focused card may remain open because card identity/correspondence authority did not change;
- return an open Oracle to the Threshold with its question preserved.

### Lens/theme/depth change

- do not rebuild deck identity;
- do not change correspondence authority;
- do not change relation method;
- do not invalidate the current canonical reading solely because interpretation/presentation settings changed.

## Authority-safe deck rebuild

A system transition keys cards by `canonicalCardId` first. For truly old numeric-only cards, the canonical 78-card legacy-index bijection is used as compatibility fallback.

Canonical target-system identity/authority is regenerated separately from preserved creative history. Target identity fields are reasserted after creative history is restored so generated layers can never mask target-system authority.

This prevents a manifested Thoth relic from remaining `THE MAGUS`, `DISKS`, or Thoth-source-qualified after switching to RWS while preserving artwork, exegesis, generation metadata, prompt state, and patina.

- an open Oracle closes to Threshold on fact-affecting doctrine changes and preserves its question;
- Bataille/Jung/Nietzsche/Bruno/etc. lens changes keep the open reading and relation truth intact;

- old ReadingRecords restore unchanged;
- old sessions missing newer fields migrate deterministically;
- Phase A, Phase B, Phase C, full Vitest/build, and Fold behavioral gates pass.
