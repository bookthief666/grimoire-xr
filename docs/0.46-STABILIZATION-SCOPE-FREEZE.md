# 0.46 Scope Freeze

Effective immediately for `agent/0.46-relic-chamber-reliquary`.

Allowed changes:
- fixes required to make the existing Relic Chamber behavior work as specified;
- fixes required to make existing Reliquary persistence/restore/forget behavior safe;
- tests, QA fixtures, verifier corrections, and acceptance documentation for those behaviors;
- accessibility/usability fixes necessary for those same behaviors.

Not allowed until 0.46 is frozen:
- new visual systems;
- new recurrence features beyond already implemented factual recurrence summaries;
- new Spirit behavior;
- new Tarot doctrine/source packs;
- new provider calls;
- new VR behavior;
- ontology migration/runtime work planned for 0.47;
- semantic package extraction planned for 0.48.

Any newly discovered issue outside 0.46 scope is documented and scheduled rather than opportunistically added to this branch unless it is a stop-the-line correctness/data-loss defect.
