# Grimoire XR

A VR-first occult tarot and grimoire application. You stand inside a dark
Thelemic/Hermetic temple chamber, before a ritual altar, and forge a deck,
lay a spread, and consult an oracle as an in-world ritual rather than a
dashboard.

Built with React 19, TypeScript, Vite, React Three Fiber, Drei and WebXR.
Card text is generated by Google Gemini; card art by a ComfyUI backend.

## Requirements

- Node 20+
- A WebXR headset (developed against Quest) for VR. The app also runs as a
  flat browser scene with a fallback UI, so a headset is not required for
  development.
- A Google Gemini API key.

## Setup

```bash
npm install
cp .env.example .env.local   # then fill in GEMINI_API_KEY
```

## Running

The client and the API are served separately in development.

```bash
npm run dev     # Vite dev server (HTTPS, LAN-accessible for headset testing)
vercel dev      # serverless handlers in api/, on :3000
```

`npm run dev` alone will start the client, but every forge/oracle call will
fail — Vite does not execute `api/`. `vite.config.ts` proxies `/api/*` to
`http://localhost:3000`; override with `API_PROXY_TARGET` if `vercel dev`
runs elsewhere.

HTTPS is enabled via `@vitejs/plugin-basic-ssl` and `server.host` is on,
because WebXR requires a secure context — open the LAN URL on the headset
and accept the self-signed certificate.

## Scripts

| Script | Purpose |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Type-checks `src/`, `api/`, and `vite.config.ts`, then builds |
| `npm run lint` | ESLint |
| `npm run preview` | Preview the production build |

## Environment

See `.env.example` for the full list. `GEMINI_API_KEY` is the only strictly
required variable; without the `COMFYUI_*` variables the app still runs and
generates text, just without card art.

## Layout

```
api/                     Vercel serverless handlers
  forge.ts               deck + dossier generation (Gemini)
  oracle.ts              oracle consultation (Gemini)
  card-image*.ts         card art generation (ComfyUI)
src/
  engine/                useGrimoireEngine - all ritual state
  services/              typed clients for the api/ routes
  types/grimoire.ts      zod schemas, single source of truth
  constants/             traditions, tones, tarot systems, art styles
  scene/                 the VR temple
    RitualChamberScene   scene root, composes everything
    RitualWorkbench      the altar; UI lives in scene/workbench/
    workbench/           altar hardware, dials, forge menu, spread, cards
    Temple*.tsx          architecture, atmosphere, xenotheurgy
    ThelemicSigils.tsx   reusable parametric occult glyphs
  App.tsx                Canvas + XR store + flat fallback UI
```

## Deployment

Vercel, zero-config: `api/*.ts` become functions and the Vite build is
served as the client. Set the environment variables from `.env.example` in
the Vercel project settings.
