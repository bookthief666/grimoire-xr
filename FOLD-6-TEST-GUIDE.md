# Galaxy Z Fold 6 · Showcase & Continuity 0.8 test ritual

Showcase & Continuity 0.8 is designed to remain useful when the Mac is unavailable. **Phone Demo** is deterministic and provider-free: it exercises the real 78-card state, card cloth, statistics, archive, sharing, restoration, gallery, patina, and spatial scene with local rehearsal text and lightweight SVG relics. Every demo result and export is labeled so it cannot be mistaken for Qwen or ComfyUI output.

## Once 0.8 is installed or hosted

1. Open `/vr` on the Fold 6.
2. Follow the automatic five-step Showcase Rite once. Each step should select both its console tab and matching spatial court.
3. Open **Ritual** and choose **Use Phone Demo · No Mac**.
4. Name a subject and choose **Awaken the Complete Grimoire**.
5. The five tabs should now work without a Mac provider.

Switching back to **Live Local AI** does not erase the current palace. Re-awaken the ritual after reconnecting if you want Qwen to replace the deterministic rehearsal deck.

## Closed cover screen

- Use portrait orientation first.
- The console should behave as a tall bottom sheet, leaving a band of the temple visible above it.
- All five tabs must remain reachable horizontally.
- Ritual readiness should form a two-column grid.
- Deck and Oracle trays should use two readable columns with approximately 48-pixel touch targets.
- Open the Spirit keyboard. The active textarea and Send button must stay visible; the performance strip should disappear while typing.
- Close the keyboard and confirm the sheet returns to its earlier height.

## Unfolded portrait

- The console should span nearly the full width as a lower sheet while preserving the altar above it.
- Scroll each tab independently; the five-station tab bar should remain sticky.
- In Oracle, select a card, place it in a slot, move it to another slot, and clear it by touching a filled slot with no tray selection.
- The short vibration should occur on card selection and placement when system vibration is enabled.

## Unfolded landscape

- The console should occupy the left side of the screen while the temple remains visible on the right.
- Close the console and reopen it with **Open Ritual Console · 93**.
- Change tabs and confirm the right-side spatial codex turns toward Scriptorium, Forge, Jupiter, Saturn, and Luna respectively.
- Adaptive Astral Weather should report tier 2 on the phone unless measured performance forces tier 1.

## Provider-free functional circuit

1. Ritual: awaken all 78 cards and manifest the local ruling Genius relic.
2. Deck: scribe one card, manifest it, inspect twice, and copy its visual prompt.
3. Grand Forge: choose **Forge Next 3**, confirm three local SVG relics appear, then test a ten-card slice.
4. Oracle: manually arrange and cast a Triad; confirm the answer begins with `DEMO CURRENT`.
5. Spirit: exchange two messages; confirm each simulated answer identifies itself as rehearsal rather than quotation or supernatural claim.
6. Archive: confirm counts and patina, download JSON, then choose **Share / Save Archive**.
7. Open the Manifested Reliquary. Swipe between full-screen cards, copy a prompt, and return one card to the Forge.
8. Change the subject, then choose **Restore JSON Archive** and select the file from step 6. Confirm the original subject, deck, images, Oracle, Spirit history, and progress return.
9. Open the exported HTML file on the Fold and verify that the local relic images are embedded.

## Install and offline rehearsal

The install button is available only from a production build on a secure context. A Termux server opened as `http://127.0.0.1:4173/vr` is device-local and qualifies; a raw `http://192.168…` Mac address does not. An HTTPS Cloudflare URL or the native Capacitor app also qualifies.

1. Run `npm run build`, then `npm run vr:preview -- --host 0.0.0.0` in Termux or on the host.
2. Open the qualifying `/vr` address in Chrome or Samsung Internet and let the temple load completely once.
3. Open Archive and choose **Install Grimoire XR**, or use the browser’s **Add to Home screen** command if it does not expose the custom prompt.
4. Launch the new home-screen icon and enable Phone Demo.
5. Turn on airplane mode, close and reopen the installed app, and confirm Ritual, local SVG forging, Oracle, Spirit, gallery, and JSON/HTML export still work.
6. Return online before switching back to Live Local AI. The offline worker never intercepts `/api`, `/health`, Ollama, or ComfyUI traffic.

## Live-AI circuit when the Mac is reachable

The Mac must run Ollama, ComfyUI, the Grimoire API, the production preview, and the HTTPS tunnel. Open the tunneled `/vr` address, select **Return to Live Local AI**, then **Recheck Providers**. Never expose raw ports 11434 or 8188; the phone should reach only the protected Grimoire boundary.

Use Samsung Internet or Chrome for the flat console. Immersive WebXR remains a Quest Browser feature; the Fold is the touch and Android acceptance device.
