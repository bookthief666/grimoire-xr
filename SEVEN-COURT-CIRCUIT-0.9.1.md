# Seven-Court Circuit 0.9.1

This pass turns the `COURTS 0/7` instrumentation into a readable ritual path. Open **Archive** at any time to see the next unfinished court, its exact requirement, and a button that moves the console and spatial temple to the relevant instrument.

## Acceptance rite

Use **Phone Demo · No Mac** for a fast rehearsal, or Live Local AI for the real outputs.

1. **Mercury · Gnosis:** name a subject and awaken the complete 78-card Grimoire.
2. **Venus · Eros:** change the Aesthetic selector after awakening, or choose **Weave Next Aesthetic**.
3. **Sol · Genius:** choose **Turn Seal · No Image** for an instant local action, or manifest the ruling portrait.
4. **Mars · Will:** scribe a card, manifest its image, then choose **Inspect + Add Patina**.
5. **Jupiter · Synthesis:** ask a question, arrange or draw a spread, and cast the reading.
6. **Saturn · Shadow:** send a Spirit message and receive its reply.
7. **Luna · Mnemosyne:** download JSON/HTML or share/save the archive.

The order is suggested, not enforced. The constellation seals at 7/7. A newly exported JSON file includes Luna's completed state immediately, so restoring that same file preserves the sealed circuit.

## Mac update and test

From the project folder after applying the update:

```bash
npm run check
npm run mobile:sync
npm run api
```

In a separate Terminal window:

```bash
npm run vr:preview
```

Open `http://127.0.0.1:4173/vr`, hard-refresh with `Command-Shift-R`, then open **Archive**. The header should read **GRIMOIRE XR · SEVEN-COURT CIRCUIT 0.9.1** and the Archive should contain the **Seven-Court Pilgrimage**.
